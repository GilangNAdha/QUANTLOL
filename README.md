# QuantLOL — XAUUSD cBot with measured risk, measured latency, measured results

A cTrader cBot for XAUUSD that combines Smart Money Concepts (sweeps, BOS/CHoCH, FVG, order blocks),
Auction Market Theory (session profile, POC/VAH/VAL, initial balance, balance vs discovery), optional
external exposure context (GEX, delta, vanna), a broker-tick-volume order-flow proxy, and VIX as
broad context.

The point of this repository is not a profit claim. It is a bot whose risk, latency and results can
be **checked**: every trade and every rejected setup is logged, every stage is timed, every
performance number comes with its sample size, and the research harness is the same rule set as the
C# engine (pinned by cross-language tests).

## The mandate the code enforces

- Fixed **0.01 lot**, $1,000 reference balance, 1:100 leverage subject to broker gold margin.
- **$5 planned risk per trade** including commission and slippage; a structural stop wider than that
  is **skipped, never tightened**.
- One position at a time, no martingale/grid/averaging up/size escalation/duplicate orders.
- **$15 daily loss limit**, **$30 equity drawdown** from the reference balance (latched kill switch).

These are limits on *planned* risk. Gaps, slippage, rejected stops or a disconnect can make a
realised loss larger; the journal records realised slippage and MAE/MFE so the gap is measured, not
assumed away (see `docs/BUILD.md` §5).
- Works with **no paid services**: broker data only; GEX/VIX are optional and clearly labelled.

## Two products in one repository

| | **cBot** (`src/QuantLOL`) | **Signals app** (`signals/`) | **Terminal** (`terminal/`) |
|---|---|---|---|
| What it is | the trading bot for cTrader | a standalone advisory signal app | a full terminal workspace around the engine |
| Runs on | cTrader Automate, C# net6.0 | plain Python 3, stdlib only | Next.js + Express (Node 22) + the Python engine |
| Can trade | yes | **no — no broker connection at all** | **no — displays what the engine decided** |
| Get started | `docs/QUICKSTART.md` | `python3 -m signals doctor` → `docs/SIGNAL_APP.md` | `./tools/terminal_dev.sh` → `docs/TERMINAL.md` |
| Live data (BTC / FX) | `docs/LIVE_DATA.md` | `python3 -m signals --preset btc doctor` | keyless providers, no API key |

The **terminal** is [OpenTerminal](https://github.com/ErTasselli/OpenTerminal) (MIT, vendored at a
pinned commit) with a QuantLOL signal panel wired to the engine over a read-only HTTP bridge — see
`docs/TERMINAL.md` and `terminal/NOTICE.md`.

Both call the **same rules** (`research/quantlol_ref.py`, parity-tested against the C# core), so a
signal you see in the app is the decision the bot would make on that closed bar.

```bash
python3 -m signals doctor                 # validate config + data + external inputs
python3 -m signals once                   # one advisory read on the newest closed bar
python3 -m signals serve --port 8080      # local dashboard at http://localhost:8080
python3 -m unittest tests.test_signals    # 69 tests, offline
./tools/terminal_dev.sh                   # engine + terminal at http://localhost:3000
```

## How to use it

`docs/QUICKSTART.md` is the full runbook. The short version:

```bash
# 1. build + test (73 tests must pass before you run anything)
dotnet build src/QuantLOL/QuantLOL.csproj -c Release   # -> src/QuantLOL/bin/Release/net6.0/src.algo
dotnet test  tests/QuantLOL.Tests/QuantLOL.Tests.csproj

# 2. install: copy src.algo to Documents/cAlgo/Sources/Robots/, press Build + Reload in cTrader,
#    attach the bot to an XAUUSD chart, keep the default parameters, set Dry run = true first.

# 3. research only (not needed to trade)
python3 research/run_pipeline.py    # regenerate research/out/report.md from the free data
python3 research/make_parity.py     # regenerate tests/fixtures/parity.json
```

Then read, in this order: `docs/QUICKSTART.md` → `docs/BUILD.md` (§3 demo verification of 0.01 lot
and the $5 cap) → `docs/FORWARD_TEST.md` before trusting anything → `docs/TROUBLESHOOTING.md` when it
does not trade.

## What is measured and what is not

Measured in this repository:
- compile and test status, on every push, in CI;
- risk arithmetic, volume conversion, drawdown guards, duplicate suppression (unit tests);
- cross-language agreement of structure, profile, order flow, risk and 12 signal decisions;
- backtest results with explicit costs, fills, walk-forward folds, cost and parameter sensitivity,
  plus every rejection reason.

Not measured here:
- profitability on live data (no forward test exists yet);
- real spreads, fills or latency (backtest assumptions are labelled as such);
- benchmark numbers for this machine (no cTrader runtime was available here; the template ships
  empty rather than filled with invented figures);
- any benefit from GEX / delta / vanna (no legitimate historical exposure series was available, so
  those variants are reported as **untested**, not as "no effect").

Nothing in this repository promises a return. The backtest is small-sample and, where it is
positive, its confidence interval includes zero.
