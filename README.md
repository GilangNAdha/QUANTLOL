# QuantLOL — XAUUSD cBot with measured risk, measured latency, measured results

A cTrader cBot for XAUUSD that combines Smart Money Concepts (sweeps, BOS/CHoCH, FVG, order blocks),
Auction Market Theory (session profile, POC/VAH/VAL, initial balance, balance vs discovery), optional
external exposure context (GEX, delta, vanna), a broker-tick-volume order-flow proxy, and VIX as
broad context.

The point of this repository is not a profit claim. It is a bot whose risk, latency and results can
be **checked**: every trade and every rejected setup is logged, every stage is timed, every
performance number comes with its sample size, and the research harness is the same rule set as the
C# engine (pinned by cross-language tests).

## The mandate the code enforces

- Fixed **0.01 lot**, $1,000 reference balance, 1:100 leverage subject to broker gold margin.
- **$5 planned risk per trade** including commission and slippage; a structural stop wider than that
  is **skipped, never tightened**.
- One position at a time, no martingale/grid/averaging up/size escalation/duplicate orders.
- **$15 daily loss limit**, **$30 equity drawdown** from the reference balance (latched kill switch).
- Works with **no paid services**: broker data only; GEX/VIX are optional and clearly labelled.

## Quick start

```bash
dotnet build src/QuantLOL/QuantLOL.csproj -c Release     # produces src.algo
dotnet test  tests/QuantLOL.Tests/QuantLOL.Tests.csproj  # 73 tests
python3 research/run_pipeline.py                         # regenerate the research report
python3 research/make_parity.py                          # regenerate the parity fixture
```

Then: `docs/BUILD.md` for the demo verification checklist, `docs/FORWARD_TEST.md` before trusting
anything, `docs/TROUBLESHOOTING.md` when it does not trade.

## What is measured and what is not

Measured in this repository:
- compile and test status, on every push, in CI;
- risk arithmetic, volume conversion, drawdown guards, duplicate suppression (unit tests);
- cross-language agreement of structure, profile, order flow, risk and 12 signal decisions;
- backtest results with explicit costs, fills, walk-forward folds, cost and parameter sensitivity,
  plus every rejection reason.

Not measured here:
- profitability on live data (no forward test exists yet);
- real spreads, fills or latency (backtest assumptions are labelled as such);
- any benefit from GEX / delta / vanna (no legitimate historical exposure series was available, so
  those variants are reported as **untested**, not as "no effect").

Nothing in this repository promises a return. The backtest is small-sample and, where it is
positive, its confidence interval includes zero.
