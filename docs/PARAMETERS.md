# QuantLOL parameter reference

Generated by `tools/gen_param_docs.py` from the `[Parameter]` attributes in `src/QuantLOL/Parameters.cs`; regenerate after changing a parameter. 88 parameters in 11 groups.

Every parameter is also validated at start-up: out-of-range values stop the bot with a clear message instead of silently trading a different configuration. Volume is **fixed**: the bot never resizes, averages up, or martingales.

## Safety-critical parameters

`Lots`, `MaxRiskPerTradeUsd`, `DailyLossLimitUsd`, `EquityDrawdownLimitUsd`, `MaxOpenPositions`, `MinRewardRisk`, `EnforceRiskCap`, `RejectIfSpecUnverified`, `StalePolicy` and `EnableGex`/`EnableVix` change what the bot is allowed to do. Changing them changes the risk mandate described in `docs/BUILD.md`; do not loosen them to make a backtest look better.
